# re: behavior

An archive of documented odd behaviors observed in large language models and adjacent AI systems.

The archive is built as static HTML, CSS, JavaScript, and JSON case files. Each case is anchored to one primary source artifact.

## Local preview

```powershell
node server.mjs
```

Then open `http://127.0.0.1:8000/`.

## GitHub Pages

This site can be served from the repository root with GitHub Pages.
